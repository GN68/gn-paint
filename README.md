# GN Paint
A simple, practical image editor inspired by the spirit of Paint.NET. for quickly manipulating images and getting things done

> [!CAUTION]
> This project is in early alpha, no instructions are provided on how to use the project as of yet

> GN Paint is a personal hobby project of mine that I will personally use for editing images, development will be slow and will be heavily tailored towards my needs as time goes on, but I am open to feedback on any socials!
